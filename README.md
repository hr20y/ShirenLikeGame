# 小さな不思議の迷宮

部屋と通路を探索するターン制ローグライクゲームのブラウザー版です。
2026年10月13日時点の実装を、Windows Forms・MonoGameへのC#移植に向けた基準として収録しています。

## 起動方法

`prototype/shiren-dungeon.html` をダウンロードし、ブラウザーで開いてください。
ビルド、サーバーの起動、追加パッケージのインストールは不要です。
HTML・CSS・JavaScriptはこの1ファイルに含まれ、描画にはCanvas、音にはWeb Audio APIを使用しています。

BGMが始まらない場合は画面を操作するか、「音をON」を押してください。

## 操作

| 操作 | 入力 |
| --- | --- |
| 上下左右へ移動 | 矢印キー / W・A・S・D |
| 斜めに移動 | Q・E・Z・C |
| 8方向へ移動 | テンキーの1〜9（5を除く）/ 画面の方向ボタン |
| 向きだけを変更 | Shiftを押しながら移動キー |
| 攻撃 | 画面の「攻撃」ボタン |
| 足踏み | Space / 画面の「足踏み」ボタン |
| 階段を降りる | 階段の上でEnter / 画面の階段ボタン |
| 持ち物メニュー | I / 「持ち物を開く」 |
| メニュー内の選択・決定・戻る | 矢印キー・Enter・Escape |

移動キー・方向ボタンの長押しで連続移動できます。
敵や壁に阻まれた移動、持ち物メニューの開閉・選択ではターンが進みません。

## 実装済みの内容

- 部屋・通路・階段の自動生成、8方向移動、ターン制戦闘。
- 全58種類のモンスターデータと、1〜30Fで自然出現する43種類の出現表。
- 各階の初期配置6体と、同じ階の30ターンごとの追加出現。
- 会心、倍速、遠距離攻撃、毒、召喚、分裂、戦鼓の強化、武者撃破後のぼうれい出現と憑依など。
- 主人公の経験値・レベルアップ・自然回復。
- 探索済みの場所の霧解除と、その範囲にいる敵の表示。
- 薬草を各階に2個配置。移動で自動取得し、最大20個を所持。
- 持ち物メニューで薬草を選択して「飲む」「置く」、足元の薬草を「拾う」。飲むとHPを20回復し、HP満タン時は消費しません。
- 薬草の使用・設置・足元からの取得は、成功時に1ターン消費。
- 次の階へのHP・レベル・経験値・毒・持ち物の引き継ぎ。
- オリジナルの合成BGM・効果音と個別音量設定。

31F以降は29〜30Fの自然出現候補を引き続き使用します。
冒険の進行状況を保存する機能はありません。保存されるのは音の設定です。
各モンスターの数値・能力と階層別の出現表は、ゲーム画面の一覧で確認できます。

## C#移植について

Windows Forms・MonoGame用のC#コードは、まだ含まれていません。
今後の移植では、マップ生成・戦闘・敵AI・アイテム・ターン進行をゲームロジックとして分離し、
描画・入力・音の処理を各画面側に実装する構成を検討します。
このHTML版を残し、移植後の動作と比較できるようにします。
